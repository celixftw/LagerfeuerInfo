# LagerfeuerInfo

WoW-Forever-Addon (deutscher Client): zeigt im Tooltip, was Lagerfeuer und Lagerobjekte bringen.

- Buff des Objekts mit dem Wert für deine Stufe (Shift: alle Stufen)
- womit sich der Buff nicht verträgt (z. B. Leitstein und Segen der Macht)
- welcher Beruf das Objekt aufstellt
- am Lagerfeuer: Übersicht „Buffs an diesem Feuer“
- **Doppelklick aufs Lagerfeuer** postet die Buffs in die Gruppe

## Installation

1. Unter **Releases** (rechts) die Datei `LagerfeuerInfo.zip` herunterladen.
2. Entpacken und den Ordner `LagerfeuerInfo` nach `World of Warcraft\_forever_\Interface\AddOns\` kopieren.
3. WoW komplett neu starten.

## Befehle

`/lagerfeuer` · `/lagerfeuer an` · `/lagerfeuer aus` · `/lagerfeuer buffs` · `/lagerfeuer posten`

Buff-Werte basieren auf [CozyFire](https://www.curseforge.com/wow/addons/cozyfire).
